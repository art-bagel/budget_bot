# catgrid-density-v1 — плотность плиток категорий

Сравнение текущей плитки категории на Dashboard с четырьмя более плотными
вариантами. Все варианты сохраняют полный набор информации: иконка с цветной
подложкой, имя до 2 строк, сумма с warn/neg-состояниями, точка семейной
категории.

Открыть: `python3 -m http.server --directory ui-redesign-concepts` → `/catgrid-density-v1/`.

Замеры на наборе из 6 категорий (высота блока):

| Вариант | Высота | Экономия |
|---|---|---|
| 0 · Текущая (иконка сверху, min-height 98px) | 330px | — |
| A · Горизонтальная (иконка слева, имя+сумма справа) | 205px | −38% |
| B · Иконка + сумма в строку, имя снизу | 239px | −28% |
| C · Компакт-вертикаль (та же композиция, ужатая) | 279px | −15% |
| D · Строки во всю ширину | 313px | −5% |

Токены скопированы из `frontend/src/styles.css` (v2 tinkoff), светлая/тёмная
тема переключается кнопкой.
