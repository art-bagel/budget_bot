## Проверки и воспроизведение

Сборщик: `scripts/crypto/build_final_history_plan.py`. Берёт неизменяемый
`outputs/crypto-eighth-block-dev/plan-800.json`, закреплённые разборы
801–900 и 901–1049, локальные исходники и исторические трассы. Февральский
диагностический сборщик используется только для формирования команд;
его строки объединяются с TON по датам и затем проходят общий пересчёт.

```sh
python scripts/crypto/build_final_history_plan.py \
  --prefix outputs/crypto-eighth-block-dev/plan-800.json \
  --output outputs/crypto-final-block-dev/plan-1049.json
python scripts/crypto/replay_first_block_dev.py \
  --socket /private/tmp/crypto-portfolio-audit.vl7Ix1 \
  --plan outputs/crypto-final-block-dev/plan-1049.json \
  --state outputs/crypto-final-block-dev/state-visible.json \
  --allow-isolated-funding-fixture --checkpoint-every 100
```

`--checkpoint-every` меняет только частоту записи локального файла состояния.
Каждый источник по-прежнему атомарно сохраняется в dev-базе. Возобновление
восстанавливает уже проведённые источники из БД с проверкой исходного хеша;
остановка между контрольными файлами не создаёт повторных проводок.
Во время проверки этот путь использован после остановки и ошибок подготовки.

- Количество main сверено после каждого нового события, итоговые собственные
  счета — с отдельными исходными лентами; биржа — с журналом дебетов/кредитов.
- Сверены EVAA, LP в фарминге, Aave, рублёвый капитал и единицы финансирования.
- Пять новых регрессионных проверок: неизменность префикса, чистые погашения,
  распределение LP/контрактов стейкинга, займы друга и отказ на неуспешной трассе.
- Полные повторы на независимом и видимом профилях не меняют проводки,
  количество и стоимость.
- Интерфейс проверен: main 1–1049, cold, подарки, Nominator 2315 TON,
  Aave с долгом 168,666998 USDC и нулевые долги EVAA. Шапка учтённых затрат
  показывает около 2 173 771 ₽: технический Bybit (4313,07 ₽) и небольшие
  внутренние остатки исключены из неё. Это не расхождение полной сверки.
  Пустые позиции EVAA ещё отображаются; очистка представления и единообразие
  стоимости карточек остаются в интерфейсной приёмке.
- Ruff для изменённых скриптов и проверка diff.

Локальные персональные артефакты в `outputs/crypto-final-block-dev/`:

## Что не следует считать закрытым этим импортом

- Пассивные проценты Aave после последнего действия и доход Nominator
  не доведены до исторического снимка на дату среза. Текущий RPC-снимок
  не подменяет исторический. Это ограничение количества/долга, а не
  пропущенные четыре февральские транзакции — они уже проведены.
- Сохраняются ранее раскрытые оценки покупок, вероятные назначения
  подарочных переводов и технический остаток старого займа друга 0,06745508 TON.
- Отдельный штраф EVAA не установлен независимо от общего изъятия залога.
- Рыночные котировки, актуальный состав LP, полный ручной ввод механик,
  исправление старой операции с пересчётом и перенос в production требуют
  отдельной приёмки. Новые доходы в production создавать нельзя: применяется
  ранее согласованная корректировка списания 31.12.2025.
