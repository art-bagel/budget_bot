## Финансирование

Загрузчик по умолчанию не создаёт доходов. Для пустого изолированного dev-владельца
в этом тесте использован явный `--allow-isolated-funding-fixture`; технические
записи помечены `DEV ONLY`. Это не разрешение на пополнения основного аккаунта.
Загрузчик по-прежнему ограничен локальным временным socket и `boundary_` базой.

нужной части расхода 31.12.2025. Оно здесь не выполнялось и не проверялось.

- Новый API-тест: банковский остаток до перевода, точные 18 знаков, перенос
  стоимости, повтор, полный откат покупки при ошибке перевода, семь отказов
  для неверных аргументов/чужого владельца.

- Шесть проверок компилятора, SQL crypto_assets и Ruff прошли.
- Исторический участок повторён без дублей.
- Отдельный запуск без флага тестового финансирования отклоняет первую покупку: ни дохода, ни обмена, ни записи журнала не создано.

  Telegram row17 показывает **−10 000 RUB / +16,42 TON** на одном банковском
  счёте. UI округляет количество для отображения; база хранит 16,4203 TON.

Открытые дефекты отображения: общая сводка «Вложено» показывает ноль, хотя
карточки имеют правильную стоимость; часы в банковской ленте показывают время
вставки, а дата — историческая. Истинное время источника сохранено в журнале.
