# Монеты как постоянные активы кошелька

Карточка монеты определяется счётом и идентификатором криптоактива. Продажа или вывод всего остатка не убирает монету из кошелька. Следующее поступление отображается в той же карточке. Закрытые партии остаются в журнале; их количества не прибавляются к текущему остатку. Монеты разных сетей/контрактов с одинаковым тикером остаются разными активами.

- Одна карточка на монету и счёт во вкладках «Все» и «Криптовалюта».
- В карточке собраны события всех прежних позиций, включая полностью выведенные.
- Пустую монету можно скрыть. Раздел «Скрытые монеты» находится внутри её кошелька; оттуда доступны история и восстановление отображения.
- Настройка сохраняется в БД отдельно для пользователя, счёта и монеты, без изменения финансовых записей.
- При ненулевом остатке монета всегда видна. Настройка скрытия применяется только к нулю.
- В криптовалютной вкладке «Закрытые DeFi» содержит отдельные завершённые позиции протоколов. Их история доступна при открытии.
- Прежнее поведение закрытых вкладов и ценных бумаг сохранено.

Реализация: `crypto_asset_visibility`, миграция 044, общий расчёт `get__crypto_wallet_asset_summary`, API видимости, группировка `walletPositions`. Балансовые позиции не переоткрываются и не переписываются ради отображения; новые поступления продолжают использовать штатные механизмы бота.

Проверка на отдельной копии и видимом dev: 76 сочетаний счёт/монета, из них 48 с нулевым остатком. Количества, себестоимость, количество событий сверены с исходными записями. Проверены скрытие/восстановление, защита доступа и отображение положительного остатка при сохранённом скрытии. Контрольные суммы финансовых таблиц неизменны. Четыре теста группировки проверяют повторные партии, пустой остаток, разные счета/активы и прежнее поведение некриптовалютных позиций.

Проверка интерфейса на dev: CATI с нулевым остатком и четырьмя событиями скрыт, открыт из раздела кошелька и возвращён в основной список. После проверки настройка восстановлена. Обе вкладки показывают по одной карточке монеты на счёт. Закрытые DeFi доступны отдельно; у строк указаны пара токенов и даты.
