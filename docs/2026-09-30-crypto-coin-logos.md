# Логотипы монет и эмблемы в DeFi

## Цель
Показывать логотип монеты везде, где есть символ; в DeFi — эмблемы всех участвующих монет
(1 монета — обычная, 2–3 — мелкие внахлёст).

## Что сделано
- Логотипы 25 монет скачаны один раз в `frontend/public/coins/` (токены TON — из поля `image`
  TonAPI, BTC/ETH/USDC/TON/MAJOR — из CoinGecko), PNG уменьшены до 96 px. Внешние сервисы в
  рантайме не нужны.
- `getCryptoIconUrl` (`frontend/src/utils/cryptoAssets.ts`) сначала ищет локальный файл по
  таблице `LOCAL_COIN_ICONS`, потом прежние CDN.
- `defiCoinSymbols` собирает монеты позиции: залог/пул, вторая монета пула, долг; до 3 без повторов.
- `CoinStack` рисует эмблемы; подключён к открытым и закрытым DeFi-позициям в портфеле и к
  карточке «Размещено в DeFi» в аналитике.

## Как добавить новую монету
Положить `<символ_нижним_регистром>.png` в `public/coins/` и добавить строку в `LOCAL_COIN_ICONS`.
Без файла показывается кружок с первой буквой.

## Известные ограничения
- Нет логотипов ECOR (источник вернул 404). Показывается буква.
- Логотипы — торговые знаки проектов; используются только для обозначения монеты.
- Поддерживается до 3 монет в позиции, реально сейчас максимум 3 у лендинга с несколькими залогами и долгом.
