# Курс TON (GRAM), DOGS, MAJOR, HMSTR при блокировке CoinGecko

29.09.2026, ветка `codex/crypto-accounting-recovery`. Выкачено в production
12:08 UTC (`150e31b`, GitHub Actions run 36565979632).

## Что было

В production не показывался курс TON. Логи API после деплоя 02:57 UTC:
`CoinGecko request failed … 429 Too Many Requests`, затем `403 Forbidden`.
403 отдаёт CloudFront («Request blocked») — и серверу, и Mac: у них один
внешний адрес. Кэш цен живёт в памяти процесса, перезапуск API при деплое его
очистил, поэтому устаревшей цены тоже не осталось.

Запасной источник TonAPI работает, но код спрашивал его только о жетонах с
адресом контракта. У нативной монеты адреса нет (`TON`, сеть `ton`,
`contract_address = ''`), поэтому TON держался только на CoinGecko. USDT на TON
(актив 15) уже получал цену из TonAPI.

## Что сделано

- `backend/app/ton_prices.py`: нативная монета запрашивается в TonAPI по
  названию — `TON` или `GRAM` (монета переименована, TonAPI принимает оба и
  отдаёт одну цену). Подделать нельзя: индекс `uq_crypto_assets_identity`
  допускает ровно одну запись (символ, `ton`, `''`).
- `backend/app/routers/crypto.py`: после ошибки CoinGecko 10 минут не
  запрашивается — повтор на каждом открытии страницы (два запроса на загрузку
  портфеля) не даёт блокировке сняться.
- DOGS, MAJOR, HMSTR лежат в Telegram Wallet (сеть `telegram`, адрес
  `service:telegram:<символ>`), а в блокчейне это TON-жетоны. Для них в
  `TELEGRAM_WALLET_JETTONS` записаны мастер-адреса, сверенные с TonAPI
  `/v2/jettons` (все три `whitelist`: Dogs, Major, Hamster Kombat). Ключ —
  точная служебная идентичность, а не тикер: неизвестный `service:telegram:*`
  цену не получает.
- Карточка позиции показывала курс с двумя знаками («0,00» для DOGS); теперь
  цены меньше 1 — с шестью, как в остальных местах.
- Тест `backend/tests/test_ton_prices.py`: нативная монета под обоими
  названиями, чужой символ без адреса не получает цену, жетоны Telegram
  Wallet — только по известной идентичности.

## Проверки

- Юнит-тесты TonAPI, `ruff`.
- Живой TonAPI с записью TON из production: TON 133,48 ₽, USDT 84,37 ₽,
  `source=tonapi`.
- Живой TonAPI: DOGS 0,0041 ₽, HMSTR 0,0145 ₽, MAJOR 3,18 ₽.
- После деплоя из контейнера API в production: TON 133,22 ₽, DOGS 0,0042 ₽,
  HMSTR 0,0144 ₽, MAJOR 3,17 ₽, `source=tonapi`; `/health` 200.

## Откат

Revert коммита; деплой пересоберёт API.

## Известные ограничения

- ETH и USDC (счета Bybit) по-прежнему берут цену только из CoinGecko и без
  него остаются без курса. Запасной источник для них — отдельная задача.
- Новая монета в Telegram Wallet получит курс только после добавления её
  мастер-адреса в `TELEGRAM_WALLET_JETTONS`.
- Кэш цен в памяти процесса: после перезапуска API цены появляются только с
  первым успешным ответом источника.
