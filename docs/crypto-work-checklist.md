## Как обновлять этот список

Следующий проход — **R3**. Затем R4 → R5 → R6; доступные результаты
для итоговой сводки можно собирать по ходу. Закрытый пункт сопровождается
отчётом/проверкой/коммитом. Составной пункт закрывается частями: импорт через API
не доказывает готовность ручного интерфейса, повтор не доказывает редактирование.
Процент готовности не вычисляем по числу флажков. 27.09 закрыты R1 и R2, результат
применён на dev. Остались согласованность интерфейса, итоговый отчёт, финальная
приёмка и разрешённый перенос в production — R3–R6.
