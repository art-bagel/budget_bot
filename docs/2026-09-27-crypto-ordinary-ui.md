# Обычный интерфейс после восстановления криптоистории

## Принятое правило

Пользовательский портфель должен выглядеть так же, как при последовательном
ручном вводе операций в чистом боте. Он показывает активы, счета, операции,
количество, себестоимость, задолженность и обычные состояния отсутствия данных.
Пояснения о сотнях, восстановлении, условных расчётах и решениях при разборе
остаются в материалах аудита, а не в карточках и ленте.

## Изменения на dev

- Убраны блоки «Точность исторического остатка», пояснения о срезе и длинные
  комментарии о методике. Вместо них обычные краткие статусы: «Нет котировки»,
  «Состав пула не обновлён», «Есть непогашенный заём».
- Служебные комментарии импорта отделены через `comment_is_system` в ответах
  API активов, DeFi и общей истории. Данные и комментарии в хранилище остаются
  нетронутыми; классификация операций продолжает использовать исходные данные.
- Новые импортеры могут задавать `evidence.comment_origin=audit`. Старый
  источник восстановления имеет явный адаптер совместимости. Привязка не
  зависит от пользователя, суммы или текста комментария.
- В редактируемой DeFi-позиции учитывается источник последнего изменения
  комментария: поздняя ручная заметка не скрывается из-за происхождения позиции.
- Обычные ручные комментарии и прежние банковские заметки сохранены.
- Объясняющие системные тексты в расшифровке ликвидации скрыты; виды списаний,
  суммы и неизвестный штраф («Сумма не указана») остаются.
- Названия двух импортированных счетов заменены на «Основной TON-кошелёк» и
  «Telegram Wallet»; исходный план подготовки использует эти же имена.
- Английские служебные подписи `legacy event`, `live-цена`, `avg`, `Unrealized`
  заменены обычными русскими названиями. Существующие компоненты и стили сохранены.

## Проверка и сохранность

`clean_portfolio_presentation.py` проверил 334 ответа API до и после:
без нового признака отображения ответы тождественны. 2008 комментариев
событий имеют служебное происхождение. На savepoint проверено, что ручной
источник сохраняет комментарий. Финансовые таблицы совпадают по контрольным
суммам; в счетах изменены только два имени. Выполнены typecheck, lint, Ruff,
6 тестов оценки DeFi; собраны и обновлены API и web в локальном Docker dev.

Повторная проверка/применение:

```sh
PYTHONPATH=.:scripts/crypto python scripts/crypto/clean_portfolio_presentation.py
PYTHONPATH=.:scripts/crypto python scripts/crypto/clean_portfolio_presentation.py --database budget_bot --apply
```

Без `--apply` изменения откатываются. Функции до обновления и результаты
сохранены в игнорируемом `outputs/crypto-clean-presentation/`.
Production не изменялся. Эта правка оформления не закрывает оставшуюся
проверку оценки подарков, общей шапки портфеля и котировок R3.
