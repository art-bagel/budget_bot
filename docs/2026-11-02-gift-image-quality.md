# Качество картинок подарков и превью для Myth Mask на проде

Уровень S: правка отображения без денег, схемы и безопасности, плюс разовая
правка данных на проде по аппруву владельца.

## Цель

После `docs/2026-11-01-gift-image.md` новые подарки получили картинку, но
мыльную. Выяснить причину и дать картинку уже заведённым подаркам Myth Mask.

## Что нашли

- `og:image` со страницы `t.me/nft/<slug>-<N>` — 160×160. Карточка рисует
  картинку в квадрате 300 CSS-пикселей (`.clx-hero__art`), на телефоне это до
  900 физических, отсюда мыло.
- Fragment отдаёт `.small.jpg` 160, `.medium.jpg` 320 (использовался),
  `.large.jpg` 640 и `.webp` 1500. Для одного подарка из каждой из 36 улучшенных
  коллекций в базе fragment отвечает 200, кроме Myth Mask — там 404 на любой
  номер и формат. Другой растровой картинки у Telegram на странице нет, только
  анимация `.tgs`.
- Сохранённое превью имело приоритет над fragment, то есть у Myth Mask оно
  осталось бы мыльным и после появления коллекции на fragment.
- Несуществующий номер t.me отдаёт 302 на `telegram.org` с пустым телом.

## Что сделано

1. `collectibleImageUrl` стал `collectibleImageUrls` — список кандидатов по
   убыванию качества: явная `image_url` (кроме превью `*.telesco.pe`), fragment
   `.large.jpg` (640) по ссылке или по коллекции и номеру, оригинал
   неулучшенного подарка, и только потом превью с t.me. `CollectibleImage` при
   ошибке загрузки переходит к следующему кандидату, иконка — когда кончились.
   Так подарок Myth Mask сам получит чёткую картинку, когда коллекция появится
   на fragment.
2. На проде десяти подаркам Myth Mask без `image_url` вписано превью с t.me
   (id 3227–3233, 3235–3237). Один `UPDATE` на id с условиями
   `image_url IS NULL` и совпадением номера, в одной транзакции, через
   `ssh master_agent@192.168.30.100` → `docker exec budget_bot_db psql -U budget
   -d budget -v ON_ERROR_STOP=1`. Все десять ответили `UPDATE 1`.

Два подарка остались без картинки: `Myth Mask #96387` (id 3234) и
`Myth Mask #21036` (id 3240). Оба заведены вручную до автозаполнения, без
ссылки, и на t.me таких номеров нет (302 на telegram.org). Скорее всего номер
записан с ошибкой; поправить номер в карточке — и подарок найдётся.

## Откат

- Код: откатить коммит ветки `claude/gift-image-fallback`.
- Данные: `UPDATE budgeting.portfolio_positions SET metadata = metadata -
  'image_url' WHERE id IN (3227,3228,3229,3230,3231,3232,3233,3235,3236,3237)
  AND metadata->>'image_url' LIKE 'https://cdn%.telesco.pe/%';`

## Известные ограничения

- Картинка Myth Mask остаётся 160 пикселей, пока коллекции нет на fragment.
  Чёткий вариант сейчас только через проигрывание `.tgs` (Lottie), это
  отдельная задача с новой библиотекой и ссылками с токеном.
- Прямой `UPDATE` на проде обошёл `calc__collectible_metadata`; значения —
  https-ссылки короче 400 символов, в пределах тех же проверок.
