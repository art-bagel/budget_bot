## Артефакты репетиции (личные данные, вне Git)

Каталог в корне проекта: `local-data/collections/release-20261002-v3/`.
Кандидат: локальная БД `collections_release_20261002_v3`.

- `manifest.json`: исходный дамп, коммит, контрольные суммы шагов.
- `verification.json`: автоматическая финансовая сверка.
- `stars-step2-clean.sql`, `inventory-import.sql`, `finalize-candidate.sql`:
  фактически выполненные финальные шаги, ограниченные именем локальной БД.
- `*.log`: результаты прогонов, включая два запуска финального шага.
- `candidate.dump`: резервная копия локального кандидата, не замена prod.
- `restore-verification.json`: создаётся после успешного восстановления
  кандидата в `collections_release_restore_20261002`.
- `crypto-summary.png`: визуальная проверка dev.
- `collections-*.py`: точные инструменты этой репетиции. Это диагностические
  сценарии, не универсальный production-установщик.

Исходник: `outputs/prod-dumps/budget_prod_20261001_154924.dump`.
SHA256: `82e08be713b653f478a68799827e1a9a922f5f2376c3c95d2462e0b2e1db1e1e`.

Первые два кандидата оставлены для диагностики, они не предназначены для
выпуска. В первом загрузчик функций ошибочно использовал старый `/Scripts`
