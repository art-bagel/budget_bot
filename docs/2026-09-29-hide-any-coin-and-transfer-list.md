# Скрытие любой монеты и список кошельков в переводе

29.09.2026, ветка `codex/crypto-accounting-recovery`, коммиты `f9aa5e3`,
`a474557`. Проверено на dev с данными production; в production ещё не выкачено.

## Цель

1. Скрывать в портфеле любую монету, а не только пустую.
2. Исправить перевод из банка в портфель: строки USDT для всех кошельков
   показывались под одним счётом, у каждого кошелька была пустая строка рублей
   и «0 USDT» вместо его остатка.

## Что сделано

- `set__crypto_asset_hidden` больше не требует нулевого остатка;
  `get__crypto_asset_detail.is_hidden` учитывает только настройку. Кнопка
  «Скрыть из кошелька» есть у любой монеты; раздел «Скрытые монеты» показывает
  настоящий остаток. Скрытие — только отображение: итоги кошелька и портфеля
  по-прежнему включают монету, количества, история и себестоимость не
  меняются. Скрытая монета остаётся скрытой после новых поступлений.
- Окно перевода: строки сгруппированы по счетам (исправлено ещё в `1944eff`,
  в production этого не было); у криптокошельков нет пустой строки рублей; у
  каждого кошелька указан его текущий остаток монеты (по открытым позициям,
  один запрос).

## Проверки

- `verify_wallet_assets.py` на копии production (dev, откат): все 76 монет
  кошельков, 51 пустая и 25 с остатком, скрываются и показываются обратно;
  кроме флага, карточка монеты не меняется; финансовые таблицы не изменились.
- Dev: список «Куда» для Main · USDT — у каждого кошелька одна строка с его
  остатком (Tangem 1 186,85574, Main TON 45,605966, остальные 0); скрытие
  JETTON с остатком 5 и возврат через API экрана.
- typecheck, lint (прежние 156/18), ruff.

## Откат

Revert коммитов; функции пересоздаются деплоем. Настройки скрытия монет с
остатком останутся в `crypto_asset_visibility`, но прежний код их не применяет
(такие монеты снова видны).

## Известные ограничения

- Скрытая монета без котировки по-прежнему оставляет «≈» у итога кошелька —
  она учитывается в стоимости.

## Известные уязвимости / осознанные риски

Для проверки в dev создавалась временная сессия владельца в dev-базе; после
проверки удалена вместе с токеном в браузере.
