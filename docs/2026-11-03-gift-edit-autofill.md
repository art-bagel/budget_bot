# Подарки Telegram: подстановка атрибутов в редакторе карточки и свёрнутое распределение затрат

Ветка `claude/gift-edit-autofill` (от `origin/main` 5984ae1). Уровень **S**
(интерфейс, деньги и схема БД не меняются; владелец поставил задачу напрямую,
план не писался).

## Цель

1. Поиск подарка на t.me, который с 01.11.2026 работает в форме «Новая
   позиция» ([отчёт](2026-11-01-gift-autofill.md)), нужен и в редакторе
   карточки. Типичный случай: неулучшенный подарок («Plush Pepe» без номера)
   улучшили, владелец вводит номер — атрибуты должны подтянуться сами.
2. В форме «Вложить» при доплате монетами сразу открывался список
   «Распределить затраты поровну на единицу» со всеми предметами счёта. Это
   редкий сценарий (одна доплата монетами на несколько предметов,
   `BUSINESS_LOGIC.md` «Распределение затрат коллекций»), и без пояснения он
   выглядел как непонятный обязательный выбор.

**Не входит:** принудительное обновление атрибутов уже заведённых улучшенных
подарков без изменения номера (пункт бэклога «Обновить из Telegram» остаётся).

## Критерии приёмки

1. В редакторе карточки подарка Telegram ввод коллекции и номера (пауза
   500 мс) вызывает `GET /portfolio/telegram-gift`; успешный ответ
   заполняет модель, фон, узор, ссылку `https://t.me/nft/…`, изображение и
   ставит «Улучшенный», под номером — «Найден <Коллекция> #<N>». Поля остаются
   редактируемыми; после «Сохранить» карточка показывает трейты и картинку.
2. Пара коллекция+номер, уже записанная у подарка, при открытии редактора
   не запрашивается (нет лишнего запроса и перезаписи ручных правок); запрос
   уходит только после изменения пары.
3. Не найден или сеть недоступна — поля не трогаются, подсказка «В Telegram
   не найден, заполните вручную», сохранение не блокируется. Если до этого в
   той же форме подарок был найден, его трейты и ссылка очищаются (чужие
   признаки не переезжают на другой номер).
4. Форма «Новая позиция» работает как раньше (тот же хук).
5. В форме «Вложить» список предметов для распределения скрыт за строкой
   «Разделить сумму на несколько предметов»; раскрытие показывает пояснение
   и прежний список с «Выбрать все». Отправка без раскрытия — обычная доплата
   на один предмет.

## Что сделано

- `frontend/src/hooks/useTelegramGiftLookup.ts` — общий хук: debounce,
  запрос, запоминание канонической пары, очистка при потере; параметр
  `known` — пара, уже записанная у предмета (критерий 2).
- `frontend/src/components/CollectibleDetailsForm.tsx` — редактор карточки
  вынесен из `Portfolio.tsx` в управляемую форму (раньше — неуправляемая
  через `FormData`, в неё нельзя было писать результат поиска).
- `PortfolioPositionDialog.tsx` переведён на тот же хук.
- `utils/telegramGift.ts` — `telegramGiftKey`, `telegramGiftTraits`.
- `Portfolio.tsx` — блок распределения обёрнут в `<details>` с подсказкой;
  стили `.pf-split*` в `styles.css`.

Коммиты: `844c5b5` (хук, форма, свёрнутый блок), `7705e10` (раскладка
раскрытого блока: `<details>` игнорирует flex-колонку `apf-field`).
