Проверены игнорируемые файлы основного проекта, прежние рабочие копии,
доступные ветки и недостижимые деревья Git. Прежний каталог
/private/tmp/budget-bot-crypto-accounting отсутствует. Искомые исправления
не скрывались правилами gitignore; в crypto был сохранён только первоначальный аудит.
Однако в локальном журнале этой задачи сохранились точные патчи и команды.

Восстановление выполнено воспроизведением только проверенных файловых правок
на исходной версии 90b3d87, без повторного запуска старых команд БД, процессов
или git. Затем изменения совмещены трёхсторонним сравнением с main ae29940.
Не были восстановлены прежние персональные расширения общей страницы Portfolio,
удалённые при выделении crypto; новая карточка актива и nullable API восстановлены.
Новые исправления публичного криптосправочника, CI, миграций и сборки сохранены.

Код сохранён отдельно от локальных финансовых материалов. .gitignore дополнен
правилами для симлинков зависимостей; рабочие копии исключены локально через
.git/info/exclude. Данные пользователя не копировались в Git заново.
