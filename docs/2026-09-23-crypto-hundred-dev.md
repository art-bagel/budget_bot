## Условие 50/50

По ответу владельца «сделай как считаешь лучше» для исторических полных выходов
сохранено прежнее распределение общей стоимости поровну между двумя монетами.
Это **условная оценка**, а не доказанная рыночная пропорция. Команда явно
задаёт `allocation_policy=equal`; положительная стоимость получает качество
`estimated`. Остаток копейки относится второй монете. Неизвестная общая
стоимость остаётся неизвестной у обеих монет. Противоречащие правилу явные
суммы отклоняются. Обычный API по умолчанию сохраняет стоимость каждой ноги.
Тест проверяет 4,67 ₽ → 2,34 + 2,33 ₽, повтор и неизвестную общую сумму.

## Интерфейс и продолжение

В локальном приложении проверены количества main, пять сущностей DeFi и
карточка TON с надписью «себестоимость неизвестна». Общие «вложено 0» и
«доход 0» заменены прочерками для разделов с криптой; карточки сохраняют
доступные оценки. Это защита от ложного нуля, не готовая сводная аналитика.
Котировки на экране сегодняшние/кэшированные; у некоторых активов нет цены.
Верхние суммы разных вкладок пока несогласованы, по ним срез не сверять.

Финальный dev-владелец **1000008**, dev-вход Telegram **1000007**, порт 5187,
API 8017. Все личные артефакты игнорируются в `outputs/crypto-first-block-dev/`:
`plan-hundred-final.json`, `state-hundred-final.json`, `evaa-first-rates.json`.
Предыдущие `state-hundred-v1/v2` — диагностические прогоны, не продолжать их.
База `boundary_usd_clean`, socket `/private/tmp/crypto-portfolio-audit.vl7Ix1`,
порт 55441. Тестовое финансирование требует отдельного флага.

```sh
python scripts/crypto/build_first_hundred_plan.py --output outputs/crypto-first-block-dev/plan-hundred-final.json
python scripts/crypto/replay_first_block_dev.py --socket /private/tmp/crypto-portfolio-audit.vl7Ix1 --plan outputs/crypto-first-block-dev/plan-hundred-final.json --state outputs/crypto-first-block-dev/state-hundred-final.json --allow-isolated-funding-fixture
```

Изменённые проведённые запросы требуют новой версии/нового изолированного
владельца. Следующий проход: конечный список оценок выше, затем итоговая
стоимостная сверка и отображение, после этого №101–200. Производство не
изменялось; восстановление части расхода 31.12.2025 остаётся отдельной задачей.
