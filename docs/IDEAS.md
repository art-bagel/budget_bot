# Идеи новых функций

Обновлено: 2026-07-06. Продуктовые идеи — новые фичи и развитие имеющихся. Отличие от
[IMPROVEMENTS.md](IMPROVEMENTS.md): там технические улучшения и UX-доводка, здесь —
функциональность. Сгруппировано по темам, внутри — от самых перспективных.

**Быстрый выбор по соотношению цена/эффект:** №3 (net worth), №5 (правила распределения
дохода), №2 (симулятор досрочки) — почти целиком собираются из существующих данных.
№1 (налоговый отчёт) — самая дифференцирующая, но требует аккуратности с методикой.

---

## Почти бесплатно на текущих данных

### 1. Налоговый отчёт по валюте и крипте
FIFO cost basis уже работает (`fx_lots`, `crypto_lots`, `lot_consumptions`), реализованный
FX-результат считается. Кнопка «отчёт о реализованной прибыли за год» (по лотам:
куплено-продано-финрез) — то, что люди мучительно собирают в Excel для декларации.
Такой фичи нет ни у одного российского бюджетника, а ~80% логики уже в БД.

### 2. Симулятор досрочного погашения кредита
График платежей (`get__credit_payment_schedule_events`) уже строится. Ползунок «+N ₽/мес» →
«закроешь на 2 года раньше, сэкономишь X на процентах». Рядом — калькулятор
«гасить ипотеку vs инвестировать» (доходность портфеля тоже уже считается).

### 3. График чистой стоимости (net worth)
Банк + портфель + крипта − кредиты, по месяцам. Все компоненты уже есть в проекциях;
нужна только snapshot-таблица (месячный джоб) и один график. Главный «мотивирующий»
экран в приложениях типа Copilot/Monarch.

### 4. Детектор подписок
По истории операций находить регулярные списания (одинаковая сумма/получатель с периодом
~30 дней — данные Tinkoff-синка это дают) → экран «Подписки: N ₽/мес» с возможностью
пометить «отменил». Люди стабильно находят 1–2 забытые подписки.

### 5. Правила автораспределения дохода
`put__record_income_split` уже умеет разбивать доход по категориям — осталось сохранять
пресеты как правила («зарплата: 10% подушка, 20% ипотека, остальное — Unallocated»)
и предлагать одним тапом при записи дохода. Половина ценности YNAB — в этом ритуале.

## Ввод данных (главное трение любого бюджетника)

### 6. Запись расхода сообщением боту
«кофе 350» в чат → бот парсит (сумма + категория по истории) → подтверждение одной
кнопкой, без открытия Mini App. Радикально снижает порог ежедневного ведения.
Парсер: начать с регулярок, потом усилить LLM.

### 7. Сканирование чеков по QR
QR на российском чеке содержит данные для API проверки чеков ФНС — из него достаются
позиции и суммы. Фото чека → операция с разбивкой. Дорого в реализации,
но очень заметно для пользователя.

### 8. Авто-категоризация расходов по истории
Для доходов уже есть `income_source_patterns` — сделать симметрично для расходов:
запоминать «описание/MCC из Tinkoff-синка → категория», при импорте проставлять
автоматически, спрашивать только про новые.

## Крипта и портфель

### 9. Импорт CSV с бирж (Bybit/Binance/OKX)
P2P-покупки сейчас матчятся вручную в xlsx. Парсер выгрузок бирж + мастер сопоставления
«P2P-покупка ↔ он-чейн поступление» превратит личный workflow в фичу.
Логично делать после TON-автоимпорта (уже в TODO).

### 10. Целевая структура портфеля и ребалансировка
Целевые доли (акции/облигации/крипта/кэш) → отклонение и «что докупить на следующие 50к».
Оценка позиций уже есть (`get__portfolio_valuation`).

### 11. Ценовые алерты через бота
«BTC ниже 80к», «USD/RUB выше 100» → сообщение от бота. Инфраструктура цен
(CoinGecko, MOEX, `fx_rate_snapshots`) уже есть; нужен фоновый чекер и таблица алертов.

## Семья

### 12. Запросы на траты из семейного бюджета
Участник создаёт заявку («5 000 из Отпуска»), владелец подтверждает в один тап из пуша.
Естественное развитие модели приглашений и готовый механизм для «детских» сценариев.

### 13. Лента активности семьи
Кто что потратил — хронологией, с реакциями. Данные (`actor_user_id` на каждой операции)
уже пишутся, экрана нет.

## Прогнозы и отчёты

### 14. Прогноз кассового разрыва
Scheduled expenses + кредитные платежи + средний дневной расход → «к 24-му числу на счёте
будет −12 000». Все три источника в БД есть; самая практичная форма «инсайтов»
после daily allowance (который уже в TODO).

### 15. Сравнение месяцев и heatmap трат
«На еду в июне на 22% больше, чем в мае» в деталке категории; календарь-теплокарта
дневных трат в аналитике. Дешёвые надстройки над `get__operations_analytics`.

### 16. «Итоги года» (wrapped)
Годовая шарабельная сводка: топ категорий, самый дорогой день, FX-результат, рост
портфеля. Дёшево, приятно, работает на удержание.

## Платформенное

### 17. Inline-режим бота
`@bot баланс` в любом чате → карточка с балансом/свободным бюджетом без открытия Mini App.

### 18. Персональный API-токен для автоматизаций
iOS Shortcuts, n8n: «записать расход» из шортката по NFC-тегу. Нишево,
но для технического пользователя — реальный сценарий.
