## Что исправлено в заключительном проходе

1. Архивный источник финансирования больше не превращает название монеты
   действующего кошелька в «?». Справочник символов берётся из всех доступных
   займов, сами архивные позиции в активную статистику не возвращаются.
2. Сравнение криптосчетов в аналитике включает DeFi и реальную остаточную
   себестоимость; устранены «Вложено 0» и ложный нулевой результат.
3. В криптовкладке скрыта общепортфельная периодная аналитика, ранее показывавшая
   купоны, депозиты и прочие чужие этому срезу доходы. Она остаётся в общей
   аналитике. Новый криптографик доходности не объявляется реализованным.
4. Таблица крупнейших монет названа «Монеты кошельков»; DeFi перечислены отдельно.
5. Чистая установка теперь создаёт include_in_statistics так же, как миграция 046.
   Диагностический результат проверки схемы сохраняется и при неуспехе.

Оформление использует существующие элементы проекта; пользовательских ID,
адресов или сумм в UI не добавлено.

## Воспроизведение dev

Из корня криптоветки, с её зависимостями:

```sh
PYTHONPATH=.:scripts/crypto python scripts/crypto/export_final_dev.py --database budget_bot
python scripts/crypto/verify_crypto_clean_schema.py
python scripts/crypto/check_user_history.py --database budget_bot
```

Последняя команда проверяет функции в откатываемой транзакции, без `--apply`.
Проверка схемы пишет только в отдельную `crypto_schema_acceptance`.
Выгрузка использует Node с поддержкой TypeScript type stripping и штатный
резолвер цен; отсутствие котировки остаётся неизвестностью. Приватные исходники,
планы и дампы нужно сохранять отдельно от git: коммит кода не является их бэкапом.
