# Криптоэкраны: приведение к общему дизайну приложения

28.09.2026. Ветка `codex/crypto-design` от `codex/crypto-accounting-recovery` (`8c856ed`).
Исходная ветка, production и финансовые данные не менялись.

## Цель

После доработок криптоучёта раздел «Портфель → Криптовалюта» и «Настройки →
Инвестиции» выбивались из дизайна приложения: столбцы из 4–9 одинаковых кнопок,
сырые форматы (`28.350000000000000000`, `1.5E-8`, ISO-даты, `coingecko`,
`ton`, секунды во времени котировки), ID во всплывающих списках, форма исправления
в стиле экрана Тинькофф, в настройках — три контрола в каждой плитке счёта и
постоянная подпись про статистику. Задача — оформление и удобство без изменения
расчётов, API-запросов и данных.

## Что сделано

Используются существующие элементы приложения, новых визуальных систем нет:

| Было | Стало | Откуда взят образец |
|---|---|---|
| 4 кнопки монеты столбцом | плитки «Зачислить / Обмен / Перевод / В банк» | плитки действий карточки категории (`cat-actions`) |
| 6–9 кнопок DeFi столбцом | плитки, сгруппированные «Залог» / «Долг», редкие действия — кнопками ниже | то же |
| история монеты — отдельные карточки, 1736 строк сразу | список с разделителями, по 30 строк + «Показать ещё» | строки ленты операций |
| белые кнопки с рамкой в подвалах криптоформ, CTA «Подтвердить обмен» в 2 строки | кнопки нижних панелей приложения, «Обменять / Перевести / Вывести» | `sh-btn`, диалог «Обмен валют» |
| `TON · ton`, `coingecko · 28.09.2026, 04:24:11` | `TON`, `CoinGecko, 28 сент., 04:24`; сеть скрыта, если совпадает с символом | — |
| `— ₽` + «Нет актуальной котировки», обрезавшее количество | «—» и «нет курса» / «нет оценки» | — |
| «Не входит в общую статистику» крупной строкой | маленький флажок «вне статистики» | — |
| скрытые монеты — кнопки «NOT · 0» | обычные строки с кнопкой «Показать» внутри карточки счёта | строки позиций |
| символы в плашках ПРОПИСНЫМИ (TSTON, STGRAM) | регистр символа сохраняется | — |
| «Залоги счёта» голым абзацем, «stGRAM · выбран» | список с количеством и отметкой открытого залога | `pf-dcond` |

| форма исправления в стиле Тинькофф, сырые числа, «версия N», «Банковский счёт №ID» | список операций, стандартные поля, «было → стало», без внутренних ID | формы нижних панелей |
| плитка счёта в настройках: шеврон + переключатель + корзина, имя в 4 строки | плитка с одним шевроном → нижняя панель: название, адрес, «В общей статистике», архив, удалить | карточка категории, «Подсказки жестов» |
| «Архив счетов» над списком | «Архив · N» под списком | — |

Также: в «Все» неизвестный доход — приглушённый прочерк вместо `— ₽ / Доход: —`;
в аналитике скрыт нулевой «Остаток» для криптовалюты (как на карточке позиций),
малые количества DeFi не округляются до 0; в списках лендинга убраны `#ID`;
чекбокс «Размер штрафа неизвестен» заменён переключателем «Штраф известен» с той
же логикой; поля по умолчанию без хвостовых нулей (`24.815282191000` →
`24.815282191`, значение то же); в ленте операций портфеля длинные суммы больше
не обрезают заголовок до нескольких букв.

## Что сохранено без изменений

- Расчёты себестоимости, финансирования, рыночной оценки, результатов, архива и
  участия счетов в статистике: ни одна функция расчёта не менялась, диффы
  затрагивают только разметку, подписи, форматирование и CSS.
- Все API-вызовы, их порядок и ключи повтора (`useCryptoRequestKey`); preview →
  apply в исправлении; переключатель статистики по-прежнему применяется сразу.
- Финансовые данные dev: в браузере только открывались экраны и формы, ни одна
  операция не отправлялась.

- `npm run typecheck` — без ошибок.
- `npm run lint` — 0 ошибок, 156 предупреждений и 18 info — те же, что до работы.
- `node --test tests/*.test.ts` — 19/19 (добавлен тест подписей сети и источника курса).
- `npm run build` — успешно.
- Визуально на dev (Vite ветки на :5173 → docker API :8000, база `budget_bot`):

  светлая и тёмная тема для новых плиток. Проверены: список криптопозиций,
  скрытые монеты, карточка монеты, карточки лендинга (с долгом и без),
  ликвидности и стейкинга, формы обмена и погашения, исправление операции
  (список и шаг редактирования без отправки), настройки счетов и архив.

## Второй проход: аналитика портфеля, закрытые DeFi, тёмная тема

| Было | Стало |
|---|---|
| Аналитика портфеля: градиентный блок «Срез» с вложенными карточками, светящиеся донаты, «пилюли» легенды, зелёные чипы периода | та же сводная карточка, что на «Позициях»; период — чипы, столбики и крупная сумма как в аналитике главного экрана; разбивки, счета, бумаги, монеты и DeFi — строки с иконкой, суммой и тонкой полосой доли в карточках как у позиций |
| «Монеты кошельков» вылезали за край экрана (количества вида `0.008812405704427 шт.`) | строки в ширину экрана, количества в формате монеты (8 знаков + символ) |
| На вкладке «Ценные бумаги» (и других) доходы за период показывали весь портфель — купоны депозитов, «Разное» | цифры периода берутся только для открытой вкладки (фильтр по `asset_type_code`, уже присутствующему в каждой месячной записи ответа API) |
| Закрытые DeFi — один общий список «Закрытые DeFi (54)» внизу | «Закрытые DeFi · N» внутри карточки своего счёта, как скрытые монеты; счёт только с закрытыми позициями показывается отдельной карточкой |
| Тёмная тема: в нижних панелях блоки баланса, плитки действий и поля ввода сливались с фоном панели | панели в тёмной теме используют цвет карточек, внутренние блоки видны; светлая тема не изменилась (тот же цвет) |
| Мятные/коралловые плашки и аватары оставались пастельными в тёмной теме (переменные `--a-*` не были объявлены) | переменные объявлены для светлой и тёмной темы |
| Активный чип периода в тёмной теме почти не отличался от неактивного | жёлтое активное состояние, как у других переключателей тёмной темы |
| Кредиты: основная кнопка чёрная/белая | жёлтая, как во всех остальных окнах |
| «−2 644 RUB», «67 333,11 RUB», «−0 ₽», «1 операций», «USDT, USDT», «USDT · ton» | «−2 644 ₽», «67 333,11 ₽», «0 ₽», «1 операция», «USDT», «USDT · TON» |

Удалены неиспользуемые стили старой аналитики (около 490 строк CSS) и
неподключённый компонент ожидающих карточных расходов (виджет ранее снят
владельцем). Проверки: typecheck, lint (те же 156/18), 19/19 тестов,
сборка; экраны — 375×812 и 1280×900, светлая и тёмная тема (переключалась
в настройках предпросмотра и возвращена на «Светлая»).

Ограничение: аналитика кредитов по-прежнему заглушка «будет доступна в
следующей версии» — это отдельная функция, а не оформление.
