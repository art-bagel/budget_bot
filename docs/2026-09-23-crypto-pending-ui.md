# Интерфейс оплат для ручного распределения

23.09.2026. В разделе портфеля «Криптовалюта» добавлен блок «Ожидают распределения».
Он показывает оплаты по всем доступным счетам, сумму и валюту, денежный счёт,
дату и категории соответствующего владельца. Есть выбор даты расхода, защита
от повторного нажатия, сообщение об ошибке, повтор загрузки и страницы по 20 строк.
Если оплат нет, блок скрывается. После распределения перезагружаются список
и портфель. Пояснение отличает учётный остаток от уже потраченных картой денег.

GET `/api/v1/crypto/pending-fiat-expenses` возвращает только доступные пользователю
нераспределённые события и регулярные активные категории того же владельца.
Суммы передаются строками. Пагинация проверяется в API и SQL.
POST `/api/v1/crypto/pending-fiat-expenses/{sale_event_id}/settle` принимает счёт,
категорию и явную дату; вызывает ранее проверенную связанную функцию расхода.
Сумму клиент не задаёт — она берётся из исходной продажи. Прямой пользовательский
путь не требует придумывать время и порядок нового импортируемого источника.
Исторический импорт по-прежнему может использовать `settle_fiat_sale` журнала.

## Проверка

46 проверок на изолированной PostgreSQL 14.15: прежние валютные сценарии,
пагинация, скрытие чужих оплат, запрет чужого распределения, допустимые категории,
повтор прямого HTTP-запроса и исчезновение распределённого события.
Ruff и TypeScript прошли. Общий lint завершился успешно с существующими
предупреждениями; новый компонент проверен отдельно.

В браузере проверен реальный компонент с синтетическим ответом API:
сумма 382,40 USD, кнопка выключена без категории, выбор категории включает её,
после сохранения оплата исчезает. Рабочие счета не использовались.

Стандартный запуск Vite выявил несовместимость установленных общих зависимостей
plugin-react/Vite (`vite/internal` отсутствует). Общие зависимости не менялись:
для проверки компонента использован временный изолированный Vite-конфиг
без React refresh, с обычным JSX-преобразованием. Полный запуск приложения
и production build в этом проходе не подтверждены. Временные файлы лежат
в игнорируемом `outputs/pending-ui-preview/`.

Результаты: `infra/db/Scripts/budgeting/tests/crypto_accounting/pending-fiat-ui-results.json`.
