# Контраст текстов ошибок — 19.10.2026

Уровень **S** (стиль, без денег, БД и безопасности). Ветка
`claude/error-text-contrast`. Долг 3 из `docs/design-guide.md`.

## Цель

Сообщения об ошибках в светлой теме читаются с нормой WCAG 4.5:1.

## Что нашли

Справочник называл только `.dlg-error`, но тот же `color: var(--neg)` на
мелком тексте ошибок стоял ещё у семи классов. Контраст `--neg` `#DF3F36` в
светлой теме: 4.28 на `--surface`, 3.92 на `--surface-inset`, 3.75 на `--bg`,
3.54 на `--neg-bg`. Токен `--neg-text` `#C2302A` для этого уже был: 5.60 /
5.12 / 4.90 / 4.62. В тёмной теме `--neg-text = --neg`, там 5.0–6.1.

| Класс | Где |
|---|---|
| `.dlg-error` | ошибки форм в диалогах и шторках |
| `.ana-cat__ops-note--error` | аналитика, список операций категории |
| `.apf-error` | форма добавления позиции |
| `.pf-detail-error` | карточка позиции портфеля (на `--neg-bg`) |
| `.fx__error` | обмен валют в шторке счёта |
| `.settings-page .danger-card__error` | удаление аккаунта в настройках |
| `.tk-error` | синхронизация Tinkoff (на `--neg-bg`) |
| `.tk-res__warn` | предупреждение в итогах синхронизации Tinkoff (на `--neg-bg`) |

Суммы, иконки и рамки на `--neg` не трогали: крупный текст и графика по
WCAG требуют 3:1, справочник оставляет им `--neg`.

## Что сделано

1. Тест: `frontend/browser-tests/a11y.spec.ts`, «error texts meet the
   contrast minimum» — на «Обзоре» рендерит элементы всех восьми классов на
   фоне страницы и проверяет axe `color-contrast` в обеих темах. На старом
   CSS упал в светлой теме на всех восьми, в тёмной прошёл.
2. `styles.css`: в восьми блоках `color: var(--neg)` → `var(--neg-text)`.
   Рамка `.pf-detail-error` осталась на `--neg`.
3. `docs/design-guide.md`: долг 3 закрыт, у `.dlg-error` указан цвет;
   `docs/TODO.md` обновлён.

Визуальные эталоны не менялись: ни на одном снимке ошибок нет.
