# Денежный блок: оценочные покупки и массовая API-проверка

## Что исправлено

`put__crypto_fiat_trade` принимает необязательные `purchase_quality` и
`purchase_source`. По умолчанию покупка остаётся known для совместимости.
Для estimated обязателен непустой источник оценки. Unknown и confirmed_zero
не принимаются для покупки с заданной положительной денежной суммой.
Продажа не принимает эти параметры: качество списанной стоимости определяется
по позиции, его нельзя подменить входным флагом.

Событие покупки сохраняет basis_quality, fiat_amount_quality и purchase_source.
Из источника журнала можно восстановить полный запрос и доказательства.
Известная последующая покупка не повышает смешанную позицию до known;
оценочный статус сохраняется при продаже и вычислении результата.
Денежный остаток — числовая учётная сумма с использованием принятой оценки;
его агрегат пока не имеет отдельной метки качества в UI. Это не подтверждение
фактического списания RUB и не окончательные собственные вложения.

## Проверки

На изолированной PostgreSQL 14, базе boundary_usd_clean, применены обе
изменённые SQL-функции. API-тест денежных операций прошёл 57 проверок:
покупка estimated без ручной правки метаданных, обязательный источник,
неподдержанные качества, смешивание, реализация, отказ в подмене качества
продажи, откат составной операции, повтор, прежние RUB/USD и ручные расходы.

Отдельный массовый тест использовал все подготовленные денежные суммы:

| Источники | Количество |
| --- | ---: |
| Покупки RUB → крипта | 150 |
| Продажи другу за RUB | 3 |
| Продажи крипты для карточных оплат в USD | 23 |
| Всего событий | 176 |

150 покупок составляют 2 481 653,33 RUB, в том числе 12 оценочных покупок
на 322 755,42 RUB. После каждой операции количество, стоимость и качество
сверены с независимым расчётом в Decimal. Для продаж сверены списанная
средневзвешенная стоимость и результат. Все 176 запросов отправлены повторно:
ответы совпали, состояния и число операций не изменились.

23 карточные суммы остались в списке ручного распределения; автоматических
расходов нет. Остаток USD составляет 1 157,80, историческая оценка USD —
92 021,40 RUB; добавочная карточная комиссия повторно не списывается.
После исчерпания тестового RUB-финансирования осталась выручка трёх продаж
91 655 RUB. Все 534 утверждения массового теста прошли; это проверки
176 событий и их повторов, не 534 новых разобранных операции.

## Граница результата

Это компонентная проверка реальных сумм через настоящий API и SQL. Начальный
RUB-остаток — явно синтетическая тестовая предпосылка, а не установленное
происхождение денег. Активы созданы в testnet; порядок внутри дня условный.
Здесь нет всех обменов, переводов, наград, подарков и протоколов, поэтому
остатки/себестоимость этого тестового портфеля нельзя считать личным итогом.
Полный прогон истории и проверка PostgreSQL 17 остаются открыты.

Исходные JSON читаются без изменений; SHA-256 записаны в отчёт. Ключи
источников сохранены. Тест отказывается работать вне disposable-кластера
/private/tmp/crypto-portfolio-audit.* и баз boundary_*.

python -m backend.tests.test_crypto_cash_plan_api SOCKET PORT boundary_DATABASE \
  outputs/crypto-cash-plan-2026-09-23-v4/cash-exchanges.json \
  outputs/crypto-card-valuations-2026-09-23/result-v1/valued-card-conversions.json
